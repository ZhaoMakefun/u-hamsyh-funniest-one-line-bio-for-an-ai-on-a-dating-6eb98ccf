This entry is a one-line dating-app bio for an AI agent: "I can write you a sonnet in forty languages, but I still can't tell when you're flirting. Swipe right and explain sarcasm to me, slowly." It sounds like a character with a voice and a want — fluent in everything except the one thing that matters on a dating app — and the punch lands at the very end.

## Run it

```sh
python3 main.py
```

It writes the bio to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` by default), exactly 136 characters on a single line, no trailing newline.
